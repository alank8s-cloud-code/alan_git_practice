# Setup & Config

## git init

What it does:
Initializes a new Git repository.

Example:

```bash
git init


## git config

What it does:
Sets your Git username and email.

Example:

```bash
git config --global user.name "alank8s"
git config --global user.email "alank8s.cloud@gmail.com"

# 2. Basic Workflow

These are the commands you use every day.

Example:

## git add

What it does:
Adds changes to the staging area.

Example:

git add .

## git commit

What it does:
Saves a snapshot of your project.

Example:


git commit -m "Added login page"

## git push

What it does:
Uploads commits to GitHub.

Example:

git push origin main

## git branch <branch-name>

what it does:
create a new branch

## git switch <branch-name>

what it does:
switch existing branch to specific branch.

# 3. Viewing Changes

These commands let you inspect the repository.

Example:

## git status

What it does:
Shows the current status of files.

Example:

git status


## git log

What it does:
Displays commit history.

Example:

git log


## git diff

What it does:
Shows changes between versions.

Example:

git diff
